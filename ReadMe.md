# Minecraft Function Expansion

## 功能：
【切石机】站在上面会被秒杀  
【发光浆果】食用后玩家会发光五分钟  
【时钟】放在第一格显示存档游玩时间  
【三叉戟】忠诚三叉戟掉入虚空自动返回  
【蜂蜜瓶】饮用去除自身的反胃与饥饿效果  
【磁石】放在第一格自动捡起五格内掉落物  
【寻觅山羊角】吹响给予所有山羊发光五分钟  
【歌颂山羊角】吹响给予20格内铁傀儡力量2两分钟  
\
无需OP权限，set后的数字填未提到的数字关闭：\
【计时器】/trigger gntz.time.t set 1  
【饥饿值】/trigger gntz.score.t set 1  
【生命榜】/trigger gntz.score.t set 2  
【去世榜】/trigger gntz.score.t set 3  
【击杀榜】/trigger gntz.score.t set 4  
【极限生存】/trigger gntz.adven.t set 1  
【闪电苦力怕】/trigger gntz.adven.t set 2  
\
将物品扔同一格触发。请勿可燃方块附近使用，会召唤闪电：\
【玩家发光】指南针+末影之眼=全员发光  
【猪灵头颅】头戴猪灵头颅时猪灵不会攻击你  
【盔甲架手臂】跟盔甲架站同一格抬头扔木棍  
【隐形展示框】八分钟隐形药水+物品展示框=隐形物品展示框  
【玩家头颅】书与笔的书名填头颅名字并署名，成书+绿宝石块=对应头颅，需正版登录  
【定点传送】需要扔到四级信标上，空地图+末影珍珠=记录位置，指南针+末影珍珠=传送玩家  
【附魔金苹果】扔在装满水的炼药锅里且锅底下有点燃的萤火，金苹果+青金石块+不死图腾=附魔金苹果
